THE MVP

One real deal, end to end. Build the Must list first. Add the Should list only if the Must list is on time

DONE
MEANSA judge can watch the platform run one real public deal: documents go in, facts appear with page and quote, the blocking clause shows as a DENIED action in the log, a new plan appears with its risk, the memo is written, and the human approval appears in the audit log.

MUST

The demo does not work without these
  1. One real deal, cached, as the proof case. Filings saved locally, with an answer key of the real clauses and what actually happened.
  2. Intake and clause reader on the real credit agreement, with the quote validator.
  3. Gateway, work-item states, audit log. Denied actions are logged.
  4. Deal math and plan search. The blocked plan appears as a DENIED action that cites the clause.
  5. Monte Carlo on the shortlist, with a run id on every result.
  6. Memo agent and reviewer console. Escalation cards, approve and reject, audit log viewer.
  7. At least four escalations working: E2 (confirm facts), E3 (unclear clause), E4 (plan blocked), E6 (final call).

SHOULD

Adds the wow, if the schedule holds
  1. Rejection becomes a policy (loop C), with a few seeded past decisions.
  2. Event injection: a rate move marks results stale, re-runs them, and raises E5.
  3. Database forks for what-if plans (Tiger Data).
  4. Catch-rate score against the answer key, shown on screen.
  5. Adversarial tests: self-approval, a prompt hidden in the agreement, a swapped plan after approval.
  6. E1: hold one document back so the agent must ask for it.
  7. A second situation (company in trouble) run through the same engine with its own profile.

CUT

Recognize it, do not build it
  • Demo coverage of seven of the eight situations. The platform is designed for all eight, and the demo runs one (raising money). The other profiles stay as written settings that are not tested. Bankruptcy means detect, stop, and escalate (proposed, not confirmed).
  • Arbitrary uploads. One working upload path is enough.
  • Accounts, login, mobile, many deals.
  • Live SEC calls on stage. Use the cache.
  • Learned objective weights. The weights are inferred settings the reviewer can change.
